Show your FlipbookMaker flipbooks on your site: paste a flipbook link into a post, or use a shortcode.

== Description ==

[FlipbookMaker](https://flipbookmaker.co/) turns a PDF into an online flipbook that opens in any browser and turns like a real book. This plugin shows those flipbooks on your WordPress site.

* Paste a flipbook link on a line of its own, in the block editor or the classic editor, and it becomes the flipbook.
* Or use the shortcode: `[flipbookmaker url="https://flipbookmaker.co/v/your-book"]`. Add `height="600"` for a fixed height, and `title="Spring catalog"` to name it for screen readers.

You need a FlipbookMaker account to publish flipbooks. The free plan works.

== External services ==

This plugin shows flipbooks hosted by FlipbookMaker (https://flipbookmaker.co/), run by Mobile Alchemy Ltd.

* When a page with a flipbook loads, the visitor's browser loads that flipbook from flipbookmaker.co.
* When you paste a flipbook link into a post, your site sends that link to flipbookmaker.co to get the flipbook's embed code.

== Installation ==

1. Install and activate the plugin.
2. Publish a flipbook on flipbookmaker.co and copy its link.
3. Paste the link into a post or page, on a line of its own.

== Frequently Asked Questions ==

= Which links work? =

Flipbook links that start with https://flipbookmaker.co/v/. A password-protected flipbook doesn't turn into an embed from a pasted link; use the shortcode, and readers enter the password in the flipbook.

= Does it add anything to pages without a flipbook? =

No. It adds no scripts or styles, and loads nothing until a flipbook is on the page.
