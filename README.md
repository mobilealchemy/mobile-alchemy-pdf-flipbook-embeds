# Mobile Alchemy PDF Flipbook Embeds

A WordPress plugin that shows [FlipbookMaker](https://flipbookmaker.co/) flipbooks on your site: paste a flipbook link into a post, or use the `[flipbookmaker]` shortcode.

Install it from the WordPress plugin directory: https://wordpress.org/plugins/mobile-alchemy-pdf-flipbook-embeds/

- `plugin/` is the plugin as it ships.
- `.wordpress-org/` holds the directory page's icon, banner and screenshots.
- Releases go out from the Actions tab ("Release to WordPress.org").
